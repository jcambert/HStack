# HermesStack M10 — Local Blazor Web UI (2026-10-10)

**Release status:** M10 milestone Done (not a separately tagged GitHub Release); [PR #20](https://github.com/jcambert/HStack/pull/20) merged and [CI #159](https://github.com/jcambert/HStack/actions/runs/38084607822) fully green on `91f6f31c9da641ecb8cc5f9dac0ec7f5722a1bb9`.

M10 adds `hstack ui` to the existing CLI to open a **local HTTPS Blazor WebAssembly + MudBlazor dashboard**, using a bundled ASP.NET Core host. It manages registered projects, their Compose/Aspire lifecycle and ports, diagnostics, agent statuses and backups; it embeds the practical French user guide and provides secure terminal command instructions for interactive agents.

**Security:** host binds numeric `127.0.0.1` only; URL fragment for one-time bootstrap, HttpOnly/Secure cookie session, strict Origin/Host/CSRF checks and no browser shell or agent credentials. Existing Docker isolation unchanged. The UI uses a self-signed temporary HTTPS certificate, which browsers may require the user to trust for this local session.

**Evidence:** candidate CI #158 and main CI #159: Linux Docker/Aspire/M3–M9 runtime security gates, API malicious-origin/replay tests, real Chrome WASM render, Windows build/unit, and three SHA-256-verified packages with bundled Web assets. **No native Windows-browser or ARM64 Web UI runtime claim.** MudExtensions remains optional and is not shipped.

**To start:** install an entire new CI artifact including `web/`, then run `hstack.exe ui` on Windows or `./hstack ui` on Linux. See [M10 user guide](../product/WEB-UI-USER-GUIDE.md) and [M10 report](../agile/M10-REPORT.md).
