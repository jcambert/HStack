The required Linux M3–M8 runtime/regression gates and Windows build/unit tests passed. The M8 smoke exercised the generated AppHost and real Docker workspace, and verified read-only/non-root isolation, restricted capabilities, localhost ports, the complete four-agent image, and OpenViking with private non-root configuration. Both PR #138 and post-merge #139 ran five successful jobs.

The post-merge release matrix produced SHA-256-verified archives:
- `hstack-win-x64`
- `hstack-linux-x64`
- `hstack-linux-arm64`

The downloadable distribution artifacts are attached to GitHub Actions #139 (not a separately published tagged GitHub Release).

## Known limitations

Linux ARM64 package creation is verified but native ARM64 runtime smoke is not included in this CI. Windows build/unit is validated, but real Aspire/Docker orchestration runtime smoke runs on Linux x64. Installations that previously created root-owned OpenViking data should back up before applying a controlled ownership migration for non-root bind mounts. Avoid world-readable secrets and do not disable TLS verification.

See `docs/agile/M8-REPORT.md` and `docs/release-readiness.md` for complete evidence.
