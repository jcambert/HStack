# PBI-2304 — DevPod Spike

**Milestone:** M9. **Status:** Research completed: No-Go for integration in V5; no external PoC executed. **Depends on:** stable PBI-2302 and initial PBI-2305 parity evidence.

## Existing Solutions Review
DevPod is a potential optional workspace-provider integration when development containers and IDE workflows justify it. HStack does not require a `devcontainer.json` from its users.

## Work
Reproduce DevPod local Docker workflow; evaluate `devcontainer.json` support, workspace lifecycle, SSH/IDE integration, mounts and permissions, persistence, project identity, corporate proxy/CA, secret handling, Windows/Linux, Compose/Aspire interaction and toolchain pinning.

## Acceptance criteria
- Document a working or failed PoC with commands, dependencies and capability matrix against native Docker.
- Prove no use of privileged execution, Docker socket inside agent workspace or host-home/secret exposure, otherwise No-Go.
- Report compatibility, benefit, maintenance cost and explicit **Go / No-Go / revisit** decision.
- No mandatory devcontainer file and no required full integration for M9 Done.
