# PBI-1901 — Automation-friendly operational CLI

**Epic:** EPIC-019  
**Priority:** High  
**Status:** Review

## Acceptance Criteria
- No-argument `hstack` renders the dashboard and an interactive Spectre.Console action menu when a terminal is interactive.
- Project lifecycle supports list/show/add/edit/remove without touching source directories.
- `hstack port list|add|remove` persists loopback-only project port declarations.
- `hstack agent status --project <project>` inspects installed agent state.
- `hstack status [project] --json` is machine-readable.
- `--quiet` is supported on the primary project/status flows.
- `hstack config validate --json` reports actionable validation results.
- `hstack compose <project> config|ps|logs` is available, with raw arguments only after `--`.
- Help text escapes literal Spectre.Console brackets.
