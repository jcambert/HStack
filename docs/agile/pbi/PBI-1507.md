# PBI-1507 — Secret filtering

**Epic:** EPIC-015  
**Priority:** Critical  
**Status:** Done

## Description
Filter durable memory writes so obvious secrets are redacted and private key material is rejected.

## Business Value
Reduces the chance that durable cross-session context becomes a secret exfiltration channel.

## Dependencies
M4 secret redaction, PBI-1501.

## Acceptance Criteria
- Known token patterns are redacted before storage.
- PEM/OpenSSH private keys are rejected.
- Rejection has an explicit diagnostic code/reason.
- Raw secret content is never written to retrieval traces.

## Security Requirements
Filtering is mandatory for HermesStack-managed durable writes.

## Observability Requirements
Failures are explicit without echoing the secret.

## Test Strategy
Unit tests for redaction and private-key rejection.

## User Stories
US-1505.

## Existing Solutions Review
Reuse HermesStack's existing secret redactor; do not duplicate secret-pattern logic.

## Definition of Done
Filter is integrated into context service and tests are green.
