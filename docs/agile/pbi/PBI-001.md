# PBI-001 — Project workspace lifecycle

**Epic:** EPIC-001 / EPIC-002 / EPIC-003  
**Priority:** Critical  
**Description:** configure, start, stop, enter and inspect one isolated project workspace.  
**Business Value:** agents can work on one project without broad host visibility.

## Existing Solutions Review

Docker Compose owns container lifecycle. HermesStack integrates it and owns project policy, validated deployment plans and UX.

## Acceptance Criteria

- project path is validated before persistence;
- workspace mounts only the project plus explicit HermesStack state/cert paths;
- container is non-privileged, drops all capabilities, uses no-new-privileges;
- no Docker daemon socket is mounted;
- ports are localhost-only;
- commands use structured process arguments, never shell interpolation.

## Test Strategy

Unit tests for mount policy and Compose rendering; Docker integration validation when Docker is available.

## Definition of Done

Implementation, tests, documentation and backlog status are updated; no known security blocker.
