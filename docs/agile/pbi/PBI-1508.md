# PBI-1508 — Context observability

**Epic:** EPIC-015  
**Priority:** High  
**Status:** Done

## Description
Explain what provider/scope/namespace was queried, what was included and what the budget excluded.

## Business Value
Makes context injection auditable instead of opaque.

## Dependencies
PBI-1501, PBI-1506.

## Acceptance Criteria
- Latest retrieval trace is persisted per project.
- `hstack context explain <project>` shows provider, scope, target, counts and estimated tokens.
- Optional query execution can generate a fresh trace.
- Doctor and security inspection include memory/provider posture.

## Security Requirements
Trace contains metadata/URIs, not provider API keys or full secret values.

## Test Strategy
Context service and CLI paths plus M6 CI.

## User Stories
US-1507.

## Existing Solutions Review
HermesStack observes integration decisions; it does not duplicate provider telemetry.

## Definition of Done
Explain/doctor/security visibility is present and documented.
