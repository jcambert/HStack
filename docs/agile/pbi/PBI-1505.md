# PBI-1505 — Agent integration through MCP/hooks/plugins

**Epic:** EPIC-015  
**Priority:** High  
**Status:** Done

## Description
Connect supported coding agents to OpenViking using first-party integrations.

## Business Value
Persistent memory works in the agents users already run without custom harness forks.

## Dependencies
PBI-1502, PBI-1503, M2 agent runtime.

## Acceptance Criteria
- Claude Code, Codex and OpenCode use the upstream unified installer.
- Hermes uses its built-in OpenViking memory provider.
- Installation happens inside the isolated workspace.
- No downloaded installer is executed through an opaque curl-to-shell pipeline.

## Security Requirements
Project user credentials only; no provider root/admin credential is passed to agents.

## Observability Requirements
CLI reports integration completion/failure.

## Test Strategy
CI verifies first-party integration paths and forbids direct curl-pipe execution.

## User Stories
US-1502, US-1503, US-1504.

## Existing Solutions Review
Use upstream hooks/plugins/MCP and Hermes native support; do not reimplement memory capture.

## Definition of Done
All four initial agents have documented first-party integration paths.
