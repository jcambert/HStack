# PBI-1702 — Portable export and cross-platform import

**Epic:** EPIC-017  
**Priority:** High  
**Status:** Review

## Description
Export portable HermesStack configuration/certificates and import them on another host with explicit project-path remapping.

## Acceptance Criteria
- `hstack export <environment.hstack>` exports configuration and certificates without project source, memory or secrets by default.
- `--include-memory` explicitly includes durable OpenViking state.
- `--include-secrets --passphrase-env <ENV>` adds secret values as an AES-256-GCM encrypted package with a PBKDF2-derived key.
- Import of an encrypted secret package requires the same passphrase environment input and re-protects values through the destination native secret store.
- `hstack import <environment.hstack> --map <old>=<new>` supports path remapping.
- Missing imported project paths fail with stable `HS8xxx` guidance.
- `--include-secrets` is not allowed without an encrypted packaging implementation.

## Security Requirements
Portable export is secret-free by default. Secret values are only included through the encrypted package; the passphrase is read from an environment variable and is never placed in command arguments or application logs.

## Definition of Done
Portable archive, import validation, path remapping and tests are complete.
