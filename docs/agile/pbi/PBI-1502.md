# PBI-1502 — OpenViking service deployment

**Epic:** EPIC-015  
**Priority:** Critical  
**Status:** Done

## Description
Deploy pinned OpenViking as the first context provider with dedicated persistence and internal networking.

## Business Value
Provides durable context without implementing a custom memory engine.

## Dependencies
PBI-1501, Docker Compose orchestration, protected secret store.

## Acceptance Criteria
- OpenViking v0.4.23 is pinned by OCI digest.
- Service storage is under HermesStack data roots.
- Host exposure is loopback-only and workspaces use the internal context network.
- Root/admin credentials are never injected into project workspaces.
- Health and stop/setup lifecycle are available.

## Security Requirements
No docker.sock, host HOME, project source mounts or LAN exposure; drop capabilities and enable no-new-privileges.

## Observability Requirements
Provider version/health available through doctor/status.

## Test Strategy
CI image verification plus security invariant gate.

## User Stories
US-1501.

## Existing Solutions Review
Use the official OpenViking image and APIs rather than rebuilding memory infrastructure.

## Definition of Done
Pinned reproducible deployment, health detection, secure lifecycle and CI gate are green.
