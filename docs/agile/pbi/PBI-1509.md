# PBI-1509 — Memory backup/export

**Epic:** EPIC-015  
**Priority:** High  
**Status:** Done

## Description
Expose project memory export/import using provider-native OpenViking pack APIs.

## Business Value
Projects can preserve or transfer memory while M7 retains ownership of the broader backup lifecycle.

## Dependencies
PBI-1502, PBI-1503.

## Acceptance Criteria
- `hstack memory export <project>` produces an OVPack archive.
- `hstack memory import <project> <file>` imports into that project's provider identity.
- Vector payload inclusion is not required for minimal export.
- CLI warns that exported archives are sensitive plaintext data.

## Security Requirements
Export/import is project scoped and never uses another project's private identity.

## Observability Requirements
Failures identify the operation without exposing credentials.

## Test Strategy
Provider API paths compile and are covered by the M6 release gate; full backup lifecycle is deferred to M7.

## User Stories
US-1508.

## Existing Solutions Review
Use OpenViking OVPack export/import rather than inventing a backup format.

## Definition of Done
Provider-native export/import and safety messaging are implemented.
