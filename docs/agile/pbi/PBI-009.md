# PBI-009 — Persistent project sessions

**Epic:** EPIC-009  
**Status:** Done

A developer can detach from a managed project session and return later without losing live panes while the workspace is running. If the workspace is recreated, Herdr restores the persisted project layout and can use official agent session references for native conversation restore.

Acceptance is proven with real Docker, project-scoped state, no host credential reuse, and preserved M1 security invariants.
