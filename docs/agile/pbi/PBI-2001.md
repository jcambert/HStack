# PBI-2001 — Multi-platform CI and delivery artifacts

**Epic:** EPIC-020  
**Priority:** Critical  
**Status:** Review

## Acceptance Criteria
- PRs run restore/build/unit tests on Linux and Windows.
- Linux runs integration tests and M3-M7 regression gates.
- Main pushes publish self-contained single-file bundles for win-x64, linux-x64 and linux-arm64.
- Delivery packages include SHA-256 manifests.
- Publish jobs depend on the Linux/Windows validation gates.
