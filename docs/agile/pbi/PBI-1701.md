# PBI-1701 — Backup and restore operational state

**Epic:** EPIC-017  
**Priority:** Critical  
**Status:** Review

## Description
Provide versioned ZIP backups for HermesStack configuration, certificates and durable project state without backing up project source directories.

## Acceptance Criteria
- `hstack backup` creates a full control-plane backup.
- `hstack backup <project>` limits project state to the selected project.
- `hstack backup --config-only` excludes project/context state.
- Full backup includes durable OpenViking state.
- `hstack restore <archive> --yes` validates the manifest and rejects path traversal.
- Project source directories are never archived.

## Test Strategy
Unit-test backup/restore round trips and portable exclusions; exercise CLI in M7 smoke CI.

US-1701.

Archive service, CLI, safety checks, tests and docs are complete.
