# PBI-1506 — Context budget

**Epic:** EPIC-015  
**Priority:** High  
**Status:** Done

## Description
Bound retrieved context by item and estimated-token budgets before it is returned to agent-facing flows.

## Business Value
Keeps durable memory useful without uncontrolled prompt growth.

## Dependencies
PBI-1501.

## Acceptance Criteria
- Default budget is 12,000 estimated tokens and 20 items.
- Per-project overrides persist in configuration.
- Excluded URIs are traceable.
- Content is not silently rewritten by the budget policy.

## Security Requirements
Budgeting must not broaden scopes or retrieve from extra namespaces.

## Observability Requirements
`context explain` reports requested/returned items and estimated tokens.

## Test Strategy
Unit tests cover item and token limits.

## User Stories
US-1507.

## Existing Solutions Review
HermesStack budgets selection only; provider-native summarization/retrieval remains upstream-owned.

## Definition of Done
Configuration, policy, trace and tests are complete.
