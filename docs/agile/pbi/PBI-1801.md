# PBI-1801 — Operational logs with secret redaction

**Epic:** EPIC-018  
**Priority:** High  
**Status:** Done

## Acceptance Criteria
- HermesStack writes application events to `.hstack/logs/hstack.log`.
- Error details pass through `ISecretRedactor`.
- `hstack logs <project>` streams Docker Compose workspace logs.
- `--tail` and `--no-follow` are supported.
- Agent-specific separation is explicitly reported as unavailable when the backend cannot provide it.

## Test Strategy
Unit-test log redaction and exercise command surface in CI.
