# PBI-002 — Agent Runtime

**Epics:** EPIC-004..008  
**Priority:** Critical  
**Status:** Done

## Description

Install and launch Claude Code, Codex, Hermes Agent and OpenCode from the managed workspace through a common harness registry, with exact toolchain pins and isolated per-project authentication state.

## Existing Solutions Review

Each upstream agent retains its official installation and authentication flow. HermesStack integrates rather than replacing those mechanisms.

## Acceptance Criteria

- exact stable versions are pinned;
- all four binaries execute in the workspace;
- direct agent execution on the host is not used by managed commands;
- authentication state persists per project and does not reuse host agent homes;
- aliases delegate to the same harness logic;
- ProjectA cannot see ProjectB agent state;
- Hermes uses the current workspace as its terminal sandbox.

## Definition of Done

Implementation, unit/integration tests, real Docker M2 smoke test, architecture/security docs and backlog/roadmap are updated.
