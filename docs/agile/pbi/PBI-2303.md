# PBI-2303 — Dagger Container Use Spike

**Milestone:** M9. **Status:** Research completed: No-Go for integration in V5; no external PoC executed. **Depends on:** stable PBI-2302 and initial PBI-2305 parity evidence.

## Existing Solutions Review
Dagger Container Use is an **alternative to evaluate**, not a replacement selected in advance. Prefer its officially supported APIs and documented workflows; do not duplicate upstream capabilities.

## Work
Timebox a reproducible exploratory prototype and compare the native baseline on isolation per agent, Git branch/worktree semantics, command history, terminal intervention, MCP, services, checkpoints, integration with Codex/Claude/Hermes/OpenCode, Herdr, OpenViking, RTK, Compose/Aspire, Windows/Docker Desktop/Linux, proxy/CA and corporate networking. Record requirements not met and version compatibility at time of spike.

## Acceptance criteria
- Produce a comparison matrix, measured operational overhead/performance with methodology, security delta and reproducible test instructions.
- Missing mandatory security guarantees produce a **No-Go**, not relaxed settings.
- Record an explicit **Go / No-Go / revisit** decision with cost/maintenance rationale.
- No automatic runtime switching and no requirement to ship a Dagger provider in M9.
