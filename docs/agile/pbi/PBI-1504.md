# PBI-1504 — Shared namespaces

**Epic:** EPIC-015  
**Priority:** Critical  
**Status:** Done

## Description
Allow explicit cross-project sharing through provider-native restricted ACL namespaces.

## Business Value
Teams can share standards or reusable knowledge without weakening private project memory.

## Dependencies
PBI-1502, PBI-1503.

## Acceptance Criteria
- Shared namespaces live under a documented OpenViking shared resource root.
- Access is opt-in and lists selected projects.
- Read is the default; write requires explicit `--write`.
- Global context remains denied in M6.

## Security Requirements
Restricted ACL mode only; owner/admin credentials remain host-side.

## Observability Requirements
Scope mapping is visible through `memory scopes` and `memory inspect`.

## Test Strategy
Mapper tests and CI ACL invariant check.

## User Stories
US-1506.

## Existing Solutions Review
Use OpenViking ACLs rather than a parallel HermesStack sharing database.

## Definition of Done
Explicit ACL sharing is implemented, documented and security-gated.
