# US-014 — Agent harness registry

As a developer, I want every coding agent exposed through one typed harness contract so that HermesStack can add or replace integrations without a central agent switch.

**Status:** Done  
**Priority:** Critical

## Acceptance Criteria

- `IAgentHarness` defines inspection, launch and configuration;
- `IAgentHarnessRegistry` resolves agents case-insensitively;
- duplicate harness ids fail fast;
- aliases and canonical commands use the same registry path.
