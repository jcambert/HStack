# US-011 — Codex workspace integration

As a developer, I want Codex available through HermesStack so that I can use it inside the isolated project workspace.

**Status:** Done  
**Priority:** Critical

## Acceptance Criteria

- the tool is pinned in `toolchain.lock.yaml`;
- `hstack codex <project>` launches it inside the selected workspace;
- its auth/state is project-scoped;
- version and state isolation are validated by the M2 Docker gate.
