# US-1507 — Explain retrieved context

As a developer I want to understand retrieved context so that I can diagnose relevance, scope and budget behavior.

## Acceptance Criteria
Given a project retrieval occurred, when `hstack context explain <project>` runs, then provider, scope, namespace, requested/returned counts, estimated tokens and included/excluded URIs are shown.

## Security Considerations
No API keys or raw secrets appear in the trace.

## Test Cases
Context budget/trace tests and CLI build gate.
