# US-002 — Start an isolated workspace

As a developer, I want to start a configured project workspace so that agents can work on the project without seeing unrelated host files.

**Priority:** Critical  
**Story Points:** 5  
**Status:** In Progress

## Acceptance Criteria

Given a project points to an exact host directory, when `hstack up <project>` runs, then the project is validated, a `WorkspaceDeploymentPlan` is built, a typed Compose override is generated, and Docker Compose starts the workspace with mandatory security invariants.

## Edge Cases

Filesystem roots, host HOME, credential directories, docker.sock, host namespaces and non-local port bindings must fail closed.

## Security Considerations

No shell interpolation; no privileged mode; no daemon socket; no implicit mounts.

## Test Cases

Mount classification matrix, Compose output inspection, optional `docker compose config` integration test.
