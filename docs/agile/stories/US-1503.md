# US-1503 — Connect Codex to project memory

As a developer I want Codex connected to my project's OpenViking identity so that relevant memory is available across Codex sessions.

## Acceptance Criteria
Given memory is enabled, when the Codex integration command runs, then HermesStack invokes the upstream OpenViking installer in the isolated workspace and preserves project-specific client state.

## Security Considerations
Only the project user credential may be consumed by the integration.

## Test Cases
M6 first-party integration gate.
