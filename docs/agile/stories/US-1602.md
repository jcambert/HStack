# US-1602 — Apply a managed update transactionally

As an operator I want HermesStack to apply an approved toolchain update transactionally so that a failed new image does not strand my running workspaces.

## Acceptance Criteria
Given one or more running workspaces, when `hstack update apply --yes` succeeds, then the candidate image is validated before the active toolchain is committed; when validation fails, the prior lock and running-workspace plans are restored best-effort.

## Security Considerations
No upstream `latest`, no TLS bypass, and no in-place package upgrades inside running workspaces.
