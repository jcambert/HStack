# US-030 — Resume a project agent session

As a developer, I want named coding-agent sessions inside my isolated project workspace so that I can detach, return later and recover the same working context.

**Status:** Done  
**Story Points:** 8

## Acceptance criteria

- the session manager runs only inside the selected project workspace;
- each project has a deterministic isolated Herdr session;
- Claude, Codex, Hermes and OpenCode use official Herdr integrations;
- session layout survives Docker workspace recreation;
- direct agent launch remains available as a fallback;
- tmux remains available without becoming a nested dependency of Herdr;
- no Docker daemon, host HOME or unrelated project is exposed.
