# US-1702 — Move an environment to another host

As an operator I want to export HermesStack metadata and remap project paths on import so that Windows/Linux moves remain explicit and safe.

## Acceptance Criteria
Given an exported environment whose old host paths do not exist, when import receives explicit `--map old=new` values, then registered projects are updated only to validated existing directories.
