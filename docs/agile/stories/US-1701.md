# US-1701 — Back up and restore HermesStack state

As an operator I want to back up and restore HermesStack control-plane state so that a host failure does not force me to rebuild configuration manually.

## Acceptance Criteria
Given HermesStack configuration and project state, when a backup is created and restored, then configuration, certificates and selected durable state are recovered while the project source directory is untouched.

## Security Considerations
Archive extraction is traversal-safe; secrets are not added to the portable export surface.
