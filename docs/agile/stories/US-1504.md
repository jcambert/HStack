# US-1504 — Connect Hermes to project memory

As a developer I want Hermes Agent to use its built-in OpenViking memory provider so that Hermes gains durable project memory without a custom plugin fork.

## Acceptance Criteria
Given memory is enabled, when the Hermes integration command runs, then HermesStack executes `hermes memory setup openviking` inside the project workspace and uses project-scoped provider configuration.

## Security Considerations
Provider admin credentials remain host-side.

## Test Cases
CLI integration path and M6 smoke validation.

**Dependencies:** PBI-1503, PBI-1505  
**Story Points:** 3  
**Priority:** High
