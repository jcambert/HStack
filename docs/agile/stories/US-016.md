# US-016 — Ergonomic agent aliases

As a developer, I want short agent commands so that launching a tool is convenient without creating a second implementation path.

**Status:** Done  
**Priority:** High

## Acceptance Criteria

- `hstack claude|codex|hermes|opencode <project>` exists;
- aliases delegate to the same harness launch path as `hstack agent run`;
- arguments after `--` are forwarded as structured process arguments;
- no shell interpolation is used.
