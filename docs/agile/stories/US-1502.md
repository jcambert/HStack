# US-1502 — Connect Claude to project memory

As a developer I want Claude Code connected to my project's OpenViking identity so that memory persists across Claude sessions.

## Acceptance Criteria
Given project memory is enabled, when `hstack memory integrate <project> --agent claude` runs, then the official OpenViking integration is installed inside the workspace and uses the project's endpoint/client state.

## Security Considerations
No root/admin provider key is exposed.

## Test Cases
M6 first-party integration gate.
