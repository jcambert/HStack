# US-1506 — Share coding standards between selected projects

As a developer I want to share a named context namespace with selected projects so that common standards are reusable without exposing private memories.

## Acceptance Criteria
Given an owner project and selected target projects, when `hstack memory share` runs, then OpenViking creates/updates a restricted ACL namespace; targets receive read access by default and write access only with `--write`.

## Security Considerations
No implicit global sharing.

## Test Cases
Shared-scope mapping and restricted-ACL CI assertion.
