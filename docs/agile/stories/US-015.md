# US-015 — Project-scoped agent authentication state

As a developer, I want each project to keep its own agent authentication state so that one project cannot inherit another project's sessions or host credentials.

**Status:** Done  
**Priority:** Critical

## Acceptance Criteria

- Claude, Codex, Hermes and OpenCode state is persisted under the selected project's HermesStack data root;
- host agent homes are never mounted implicitly;
- `stateScope: isolated` is the M2 default and non-isolated scopes fail closed;
- ProjectA/ProjectB isolation is proven by the Docker gate.
