# US-1508 — Backup project memory

As a developer I want to export and import project memory so that durable context can be preserved independently of a workspace container.

## Acceptance Criteria
Given memory is enabled, when `hstack memory export <project>` runs, then a project-scoped OVPack is produced; when imported back into that project, the provider-native import path is used.

## Security Considerations
CLI warns that OVPack exports are sensitive plaintext data; cross-project identity reuse is forbidden.

## Test Cases
Provider export/import compile paths and M6 release gate.
