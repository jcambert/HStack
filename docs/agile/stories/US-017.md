# US-017 — M2 real-Docker validation

As a maintainer, I want a real Docker acceptance gate for M2 so that pinned agents, runtime isolation and state persistence are validated before promotion.

**Status:** Done  
**Priority:** Critical

## Acceptance Criteria

- the image builds from the pinned toolchain;
- all four exact agent versions execute;
- all public aliases execute in the workspace;
- ProjectA agent state is writable and ProjectB state is not mounted;
- M1 non-root, no-Docker-socket, capability and no-new-privileges guarantees remain green.
