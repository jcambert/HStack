# US-1501 — Start OpenViking

As a developer I want HermesStack to start a pinned OpenViking service so that durable context is available reproducibly.

## Context
M6 uses OpenViking as the initial context provider.

## Acceptance Criteria
Given Docker is available, when memory is enabled and a project starts, then the pinned provider is healthy on the internal context network and host access is loopback-only.

## Edge Cases
Unavailable Docker/provider fails explicitly.

## Security Considerations
No project source, docker.sock, host HOME or admin credential enters the provider/workspace unexpectedly.

## Test Cases
Pinned image, health and security invariant CI checks.
