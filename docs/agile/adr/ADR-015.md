# ADR-015 — Agent harness registry with isolated project state

**Status:** Accepted  
**Date:** 2026-10-05

## Context

M2 introduces four independently evolving upstream coding agents. A central switch would couple HermesStack releases to each tool and shared host credentials would break workspace isolation.

## Decision

Every managed agent implements `IAgentHarness` and is resolved through `IAgentHarnessRegistry`. Harnesses adapt launch, version inspection, project defaults and the upstream authentication entry point.

All authentication/session state defaults to project scope. The host user's existing agent homes are never mounted automatically.

Hermes Agent runs with `TERMINAL_ENV=local` because the Docker workspace itself is the sandbox boundary.

## Consequences

Adding an agent is additive rather than a central dispatch edit. Authentication is repeated per isolated project unless a future explicitly approved shared/custom state policy is selected.
