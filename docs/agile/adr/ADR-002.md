# ADR-002 — No Docker socket in agent workspaces

**Status:** Accepted  
**Date:** 2026-10-05

## Context
Docker daemon access effectively grants broad host control.

## Decision
Docker sockets, Windows Docker engine pipes and equivalent daemon endpoints are forbidden for managed agent workspaces.

## Alternatives
Socket proxy, Docker-in-Docker.

## Consequences
Container-building workloads require a future explicit execution strategy; host isolation is not silently weakened.
