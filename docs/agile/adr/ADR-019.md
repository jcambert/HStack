# ADR-019 — Security inspection compares policy with live Docker state

**Status:** Accepted  
**Date:** 2026-10-05

## Decision

`WorkspaceDeploymentPlan` remains the policy source of truth. When a workspace exists, `hstack security inspect` also reads Docker's effective container state. Stopped workspaces are still inspectable from the declared plan.

docker.sock, privileged mode, host networking and a host-root mount always score Critical.
