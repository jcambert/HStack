# ADR-018 — Secret values stay outside YAML and Compose

**Status:** Accepted  
**Date:** 2026-10-05

## Decision

HermesStack stores only secret policy metadata in YAML. Values use `LocalProtectedSecretStore`: Windows DPAPI current-user protection or AES-256-GCM with a user-readable-only local master key on Unix-like hosts.

Agent values are passed as exec-process environment only after project + agent + policy authorization. They are never written to the workspace service environment.
