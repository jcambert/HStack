# ADR-021 — Token metrics carry evidence and privacy semantics

**Status:** Accepted  
**Date:** 2026-10-05

## Decision

Every gain is classified Measured, Estimated or Unavailable.

RTK gain is Estimated because upstream derives token counts from shell-output size. HermesStack never converts that number into LLM cost savings.

RTK's local tracking database is redirected to workspace tmpfs and recall is disabled. HermesStack's durable metric store contains aggregates only: timestamp, project, agent attribution when available, provider, raw/optimized/saved token estimate and percentage.
